# Red Willow Ventures — Published Research Records
Contact: redwillowventures@proton.me

A mirror of the published research records of Red Willow Ventures LLC (Green Valley, Arizona).

The canonical versions are the Zenodo deposits; every file in this repository is byte-identical to its Zenodo deposit, verified by MD5 checksum against the deposit record. All records are published under CC BY 4.0.
